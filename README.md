# Jiang Weijia Portfolio

交互式森林浮岛作品集，包含游戏与产品、摄影、创意编程、写作、内容运营、个人经历和联系方式。主入口中英双语，阅读正文为中文。

## 本地运行

需要 Node.js 24 或更新版本。运行 `npm start`，打开终端显示的本地网址。Three.js 与模型、摄影、工牌和 PDF 均随站点提供，不需要构建步骤。

运行 `npm test` 可检查模型资源、树干连接、相机、动物运动、作品入口、摄影、挂绳和性能策略。

## GitHub Pages

仓库 Settings → Pages 中选择从 `main` 分支的根目录发布。`.nojekyll` 保留原始静态文件，所有站点引用使用相对路径，支持项目子目录。

`assets/island.glb` 是标准 GLB 文件，不依赖特定托管平台的 gzip 响应头。

摄影、作品集、个人工牌及其他个人资料归作者所有。购买及生成的 3D 素材仅用于该作品集展示；本仓库公开不代表向其他使用者授予素材再分发或商业使用许可。

画质会根据设备温和调整，保留抗锯齿、完整纹理和阴影。真实帧率取决于设备、浏览器、网络与显卡加速状态。
